# ABSTRACT

*This project presents the design and implementation of **"AN AUTONOMOUS MULTI-AGENT MULTI MODEL FRAMEWORK FOR END-TO-END SOFTWARE DEVELOPMENT"**, an advanced orchestration system designed to automate complex software engineering lifecycles. Traditional AI assistants often operate in isolation, lacking the context and multi-step reasoning required for production-scale development. This research addresses these limitations by introducing a collaborative multi-agent architecture where specialized agents—including architects, developers, reviewers, and testers—interact through a shared memory bus and a dependency-aware task execution engine.*

*The framework leverages a Directed Acyclic Graph (DAG) for task scheduling, ensuring that project goals are decomposed into logical, sequential steps with automated assignment and parallel execution capabilities. A robust tool-calling system provides agents with secure access to local filesystems, shell environments, and web resources, enabling them to perform end-to-end tasks from requirement analysis to final testing. The system is multi-model by design, allowing seamless switching between OpenAI, Anthropic, and Google Gemini models to optimize for cost and performance.*

*Experimental results demonstrate that the multi-agent approach significantly reduces the time required for software prototyping and bug fixing while maintaining high code quality through an iterative critic-loop mechanism. The integration of a real-time Terminal User Interface (TUI) ensures that human developers remain in control through an interactive approval flow for critical operations. This work contributes a scalable, production-ready blueprint for the future of autonomous, multi-agent software engineering.*
